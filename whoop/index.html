Personal WHOOP Data Pull Privacy Policy

Last updated: October 19, 2026

This is a private, single-user script that reads the developer’s own WHOOP data through the WHOOP API so it can be viewed next to the developer’s own workout log. It is not published, not distributed and not available to anyone else.

The short version

  • Only the developer’s own WHOOP account is connected. No other person’s data is requested.
  • Data is saved only on the developer’s own computer. It is not uploaded to any server, shared, sold or used for advertising.

Information handled

  • WHOOP data: recovery, sleep, strain, workouts and body measurements, as allowed by the scopes the developer approves.
  • Access tokens: kept in a local file on the developer’s computer and used only to call the WHOOP API.

Deletion

The developer can revoke access at any time in the WHOOP app and delete the local files.

Changes

If this policy changes, the updated version will be posted on this page with a new date.

Contact

Questions can be opened as an issue on the GitHub repository.
